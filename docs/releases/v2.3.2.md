# codex-usage v2.3.2

`v2.3.2` fixes Windows upgrades that could fail with `Access is denied` while replacing the installed executable.

## Recoverable Windows upgrades

- The installer now finds running codex-usage processes by the installed executable's exact full path, so it can recover even when the PID file is missing or stale.
- Process termination is checked and the installer waits for the old process to exit before replacing the executable.
- Startup registration, the PID file, and the launcher script are removed only after the process has stopped successfully. A stop failure now aborts the upgrade without leaving the installation half-uninstalled.
- Exact-path matching avoids terminating unrelated processes that merely share the `codex-usage.exe` filename.
- If Windows denies access because the existing daemon has a higher integrity level, the error identifies the PID and asks the user to retry `install` as administrator.

## Validation

- Windows regression tests cover recovery without a PID file and preservation of service metadata after a simulated access-denied failure.
- A real Windows upgrade was completed after temporarily removing the live service's PID file; the installer found the residual daemon, replaced the executable, recreated autostart metadata, and preserved the existing local statistics.
- Go tests, `go vet`, the Playwright Dashboard and synthetic Demo suites, and Windows/Linux amd64/arm64 builds are part of the release gate.

## Upgrade notes

Download the v2.3.2 binary and run `install` again. If a previous elevated daemon is still running and Windows reports access denied, run the new binary once with **Run as administrator**, then execute `install`. Existing local statistics, configuration, and pricing overrides are preserved.

`v2.3.2` 修复 Windows 升级时替换已安装 EXE 可能出现的 `Access is denied`。

安装器现在会按安装目录中 EXE 的完整路径查找旧进程，即使 PID 文件已经缺失或过期，也能识别残留 daemon。它会检查停止结果并等待旧进程真正退出，之后才删除登录启动项、PID 文件和启动脚本；如果停止失败，升级会立即中止并保留原有安装状态，不再进入“进程仍运行、记录却已删除”的半卸载状态。完整路径匹配也避免误杀仅文件名相同的其他进程。

如果旧 daemon 的权限级别更高，错误会显示具体 PID，并提示以管理员身份重新运行新版安装器。升级不会删除现有本地统计、配置或定价覆写。
