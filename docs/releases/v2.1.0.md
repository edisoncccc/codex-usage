# codex-usage v2.1.0

`v2.1.0` makes the local dashboard substantially faster and easier to read while tightening replay-aware JSONL accounting. It also simplifies the Standard API-equivalent estimator to the short-context prices used by the current Codex context limits.

## Performance and continuous updates

- Added a metadata-only activity probe every 30 seconds. Full incremental scans run only after JSONL changes, with a 10-minute fallback scan.
- Added a separate read-only SQLite pool and targeted indexes so dashboard queries no longer queue behind ingestion writes.
- Moved daily timeseries and pricing aggregation into SQLite, reducing full-history pricing allocations from roughly 122 MB to roughly 2.35 MB on the validation dataset.
- Added a lazy, revision-cached `/api/v1/dimensions` endpoint. Opening the dashboard no longer runs three full-history breakdown queries just to populate filters.

## Accounting and pricing fixes

- Fixed single-`session_meta` fork rollouts that omit the later parent marker. The inherited baseline is derived from the first total-minus-last snapshot, so copied parent history is not charged to the child.
- Upgrading the derived database to schema v5 performs one automatic JSONL rebuild so older fork attribution is repaired consistently. Source JSONL is never modified.
- Removed long-context thresholds and multipliers from the bundled catalog and estimator. Every recognized model now uses the published Standard short-context Input, Cached Input, Cache Write, and Output rates.
- Removed the misleading `long_context_uncertain` unpriced reason. Unknown or internal model IDs still remain explicitly unpriced unless the user adds a local alias or custom rate.
- Refreshed the bundled Standard text price check date to August 4, 2026.

## Dashboard and accessibility

- Added local display settings for font size, density, theme, motion, and language, with immediate preview and browser-only persistence.
- Raised the default type scale and improved supporting text, dialogs, tables, mobile layouts, and reduced-motion behavior without hiding fields.
- Expanded Playwright coverage for lazy filter loading, display preference persistence, responsive layout, localization, pricing, and the synthetic GitHub Pages demo.

## Release reliability

- The release workflow now uploads only the four platform binaries and `SHA256SUMS`; it no longer attempts to upload the generated `dist/pages/` directory.
- Windows and Linux amd64/arm64 remain available as single-file, CGO-free binaries.

## Upgrade notes

The first v2.1.0 startup may take longer while schema v5 rebuilds derived usage events from local session JSONL. Prompts, replies, reasoning text, credentials, and tool output are never read. Cost remains a local Standard API-equivalent estimate, not an OpenAI bill or account quota.
