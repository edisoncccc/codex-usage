# codex-usage v2.2.0

`v2.2.0` makes Session details easier to find and compare, while simplifying the Dashboard and README for people who just want to understand their local Codex usage.

## Session search and cost

- Added a frontend search box to Session details. It searches Thread titles, Session IDs, projects, models, and sources with a short debounce, and includes a one-click clear action.
- Added API-equivalent cost and token pricing coverage to every Session row. Unknown or internal models remain visibly unpriced unless a local pricing override is configured.
- Added an “Only this Session” quick filter.
- Model, source, Agent, project, and Session quick filters now toggle off when clicked again, making it easy to return to the full list.
- Session pricing is grouped in one bounded database query and reuses the same built-in catalog and local pricing overrides as the rest of the Dashboard.

## Clearer Dashboard

- Removed decorative labels and repetitive explanatory copy from the main views.
- Kept key states, field labels, pricing coverage, and accessibility text while reducing visual noise on desktop and mobile.
- Preserved the three primary views—Overview, Daily, and Details—without adding another navigation layer.

## Public-first documentation

- Moved “Install directly” immediately after “Understand it in 30 seconds.”
- Rewrote the opening sections in everyday language around the questions people actually want answered: which computer, project, model, or Session used the tokens.
- Moved JSONL, SQLite, fork replay, and estimator implementation details into a clearly marked technical section later in the README.
- Updated both Simplified Chinese and English documentation.

## Validation

- Go unit and integration tests, `go vet`, and the full Playwright Dashboard suite pass.
- Desktop and 390 × 844 mobile layouts were checked for search behavior, filter toggling, cost rendering, and horizontal overflow.
- Windows and Linux amd64/arm64 remain available as single-file, CGO-free binaries with `SHA256SUMS`.

## Upgrade notes

Run `install` again with the v2.2.0 binary. Existing local statistics and pricing overrides are preserved. Cost remains a local Standard API-equivalent estimate, not an OpenAI bill or account quota.
