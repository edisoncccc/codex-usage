# codex-usage v1.0.0

`v1.0.0` is the first stable-interface release of local-first Codex usage analytics. Per-machine attribution is its signature entry point; model, token-category, project, Thread, Session, Agent, local-day, and Standard API-equivalent-cost views turn a total into explainable local usage. This release also adds complete Chinese/English localization and a safe interactive demo built entirely from synthetic data without changing the existing accounting or automation interfaces.

## Highlights

- Complete `zh-CN` / `en` Dashboard localization, including dates, numbers, ARIA labels, empty states, Toasts, filters, pricing, and data-quality labels.
- Multi-dimensional local attribution across machines, models, token categories, projects, Threads, Sessions, Agents, and calendar days, with pricing coverage and an auditable source-merging trail.
- Dashboard locale precedence: `?lang=en|zh-CN`, saved header-button choice, browser locale, then Chinese fallback.
- Global CLI language selection with `codex-usage --lang en install` or `CODEX_USAGE_LANG=en`; Windows UI locale and Linux locale variables are used when neither is set.
- GitHub Pages Live Demo that reuses the production frontend and intercepts every `/api/v1/*` call with a session-only synthetic adapter.
- A clearer bilingual README with direct Windows/Linux downloads, a 14-second GIF, explicit scope boundaries, and a 30-second explanation.
- Bilingual launch assets: 1280×640 Social Preview and 20–30 second Chinese/English MP4 walkthroughs.

## Compatibility

- Token accounting, JSONL scanning, OTel collection, SQLite storage, JSON/CSV fields, and all `/api/v1/*` schemas are unchanged.
- No macOS support, cloud sync, account quota, billing access, Homebrew, or Scoop was added.
- The tool still never reads `auth.json`, prompts, replies, reasoning, or tool output.

## Demo privacy

The Live Demo reads no local files, sets no cookies, loads no analytics, and makes no external requests. Its machine, path, Session, usage, warning, and pricing data are synthetic and reset on refresh.

## Downloads

Release assets include Windows and Linux binaries for amd64 and arm64 plus `SHA256SUMS`. Verify your download before running it. Windows SmartScreen may show a reputation warning because the binaries are not code-signed; compare the SHA256 checksum and download only from this repository's Release page.
