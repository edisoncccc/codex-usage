# codex-usage v2.3.0

`v2.3.0` adds precise hourly usage, makes the Dashboard feel immediate when switching views, and strengthens accounting, export, cache, and browser-origin boundaries.

## Hourly token usage

- Added a rolling “Last 60 minutes” summary based on each JSONL token increment's own timestamp.
- Added an interactive line chart for the last 24 complete local hours. Every point supports pointer, keyboard, and screen-reader inspection.
- Unified Daily and Hourly trends in one panel. Daily is the default view, and Hourly can be opened without adding another section to the page.
- Fixed chart-marker drift by placing the SVG line and interactive points in the same 180 px coordinate system.

## Faster interactions

- Primary views now become visible immediately while their data continues loading progressively.
- Session rows are loaded separately from API-equivalent pricing estimates, so opening Details no longer waits for all pricing work.
- Added bounded revision-aware caches for expensive dimensions, session pricing, and related Dashboard queries.
- Reuses current results when revisiting the same range and data revision instead of repeating equivalent requests.

## Reliability and security

- Pricing aggregation validates token coherence per event, preventing opposite malformed totals from cancelling after SQL aggregation.
- JSON and CSV exports walk one stable SQLite snapshot in deterministic order, avoiding OFFSET pagination gaps or duplicates during concurrent updates.
- Session metadata advances `data_revision` only when its stored values actually change.
- Browser mutation endpoints require an exact same-port HTTP loopback Origin and reject cross-site browser requests without Origin.
- Updated SQLite and Playwright dependencies while preserving JSONL as the sole formal token-accounting source.

## Validation

- Go unit and integration tests and `go vet` pass.
- The complete Playwright Dashboard and synthetic Demo suite passes, including repeated mobile Session-loading regression coverage.
- Desktop and 390 × 844 mobile layouts were checked for trend switching, point alignment, keyboard interaction, and horizontal overflow.
- Windows and Linux amd64/arm64 remain available as single-file, CGO-free binaries with `SHA256SUMS`.

## Upgrade notes

Run `install` again with the v2.3.0 binary. Existing local statistics, configuration, and pricing overrides are preserved. The Dashboard still reads local Session JSONL as its formal usage source, and API-equivalent cost remains an estimate rather than an OpenAI bill or account quota.
