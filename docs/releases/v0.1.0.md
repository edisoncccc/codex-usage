# codex-usage v0.1.0

首个公开版本，解决“同一个 Codex 账号在多台电脑上使用，但无法知道每台电脑分别用了多少 Token”的问题。

## 主要功能

- Windows/Linux 逐电脑 Token 统计
- 自动扫描本机历史 Codex session
- 通过官方 OTel 指标接收未来实时用量
- 本地 Dashboard，支持模型、项目、Thread、来源和 Agent 筛选
- JSON/CSV 导出与命令行摘要
- 数据缺口、累计回退和历史未归属信息可见
- 所有数据保存在本机，Dashboard 只监听 `127.0.0.1`

## 下载

- Windows x64：`codex-usage-windows-amd64.exe`
- Windows arm64：`codex-usage-windows-arm64.exe`
- Linux x64：`codex-usage-linux-amd64`
- Linux arm64：`codex-usage-linux-arm64`
- 完整校验：`SHA256SUMS`

安装命令和工作原理见仓库首页 README。
