# codex-usage v2.3.1

`v2.3.1` expands hourly history beyond the latest day and gives both hourly and calendar date navigation a clearer, more consistent interaction model.

## Browse any local day by hour

- The Hourly view now has previous-day, next-day, exact-date, and Today controls.
- Selecting a date shows its complete local hours while preserving the existing interactive line chart and point-level keyboard, pointer, and screen-reader inspection.
- The selected point remains the source for the prominent Token total and category ledger, so the chart and summary always describe the same hour.

## Hourly cost and model context

- Added a second summary row below the chart for Standard API-equivalent cost, used models, and pricing coverage.
- API-equivalent cost is the primary value in that row. Model chips show each model's Token usage and estimate without presenting the result as an OpenAI bill.
- Pointer scrubbing is debounced and stale requests are ignored, keeping point inspection responsive while reusing the existing revision-aware API cache.

## Direct calendar dates and refined controls

- The Daily calendar now supports selecting an exact date directly, including zero-usage dates, and jumps to the corresponding month automatically.
- Hourly and Daily date pickers share one dashboard-specific visual component with a readable year/month-day hierarchy, larger typography, a clear calendar glyph, and larger navigation targets.
- The native date picker remains underneath the custom presentation, preserving system date selection, keyboard focus, localization, and accessibility.
- Desktop and 390 px mobile layouts keep the complete date navigator on one line without page-level horizontal overflow.

## Validation

- Go unit and integration tests and `go vet` pass.
- The complete Playwright Dashboard and synthetic Demo suite passes (15/15), including direct-date navigation and explicit date-type size assertions.
- Windows and Linux amd64/arm64 remain available as single-file, CGO-free binaries with `SHA256SUMS`.

## Upgrade notes

Run `install` again with the v2.3.1 binary. Existing local statistics, configuration, and pricing overrides are preserved. Session JSONL remains the formal usage source; API-equivalent cost remains a public-price estimate rather than an OpenAI bill or account quota.
