# codex-usage v2.3.3

`v2.3.3` completes the Windows installer reliability fix by allowing more time for the first local health check.

- The post-install health window is now 30 seconds instead of 12 seconds.
- This accommodates first-run Windows security scanning and temporarily busy machines without weakening the existing health requirement.
- The installer still polls locally, fails closed, and removes a service that remains unhealthy after the deadline.
- All v2.3.2 exact-path process discovery, checked termination, missing-PID recovery, and metadata-preservation fixes remain included.

Run `install` again with the v2.3.3 binary. Existing local statistics, configuration, and pricing overrides are preserved.

---

`v2.3.3` 补全 Windows 安装器可靠性修复：安装后的本机 health 等待窗口由 12 秒延长到 30 秒，为首次运行时的 Windows 安全扫描和临时高负载留出余量，同时仍保留本机轮询、超时判定和失败服务清理。

v2.3.2 中按完整路径识别旧进程、确认停止结果、缺失 PID 恢复以及失败时保留服务元数据的修复全部保留。使用 v2.3.3 再次运行 `install` 即可；现有本地统计、配置和定价覆写不会被删除。
