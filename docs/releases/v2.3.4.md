# codex-usage v2.3.4

`v2.3.4` fixes severely inflated token totals in newer Sol Ultra sessions that use many Subagents, and adds exact-day controls to Details.

- Newer Subagent rollouts can copy the parent session's complete cumulative token history before the child begins. The scanner now finds the child's UUIDv7 `task_started` boundary and counts only the child's own increments.
- Legacy explicit-boundary and single-metadata fork formats remain supported.
- The derived-data schema is now v6. Existing databases are preserved and marked for an explicit historical rebuild so no local statistics are silently destroyed. Confirm the rebuild in the Dashboard to correct previously indexed history.
- Details now supports Today, an arbitrary single-day picker, and a Date field in Filters. The local API also accepts `date=YYYY-MM-DD`.
- API-equivalent prices remain estimates based on Standard API text-token pricing; they are not ChatGPT subscription usage or a bill.

Validation covered the full Go test suite, `go vet`, 16 Playwright Dashboard/demo tests, a four-platform release build, and an isolated rebuild of 621 local rollouts.

---

`v2.3.4` 修复新版 Sol Ultra 大量调用 Subagent 时 Token 总量严重虚高的问题，并为“明细”页补充精确到单日的查看能力。

- 新版 Subagent rollout 可能在子会话真正开始前复制父会话完整的累计 Token 历史。扫描器现在通过子会话 UUIDv7 对应的 `task_started` 边界，只统计子代理自身的新增用量。
- 继续兼容旧版显式重放边界和单 metadata fork 格式。
- 派生数据 schema 升至 v6。升级时不会静默删除现有统计，而会提示明确确认历史重建；请在 Dashboard 中确认重建，以修正此前已经写入统计库的重复数据。
- “明细”页新增“今日”、任意单日日期选择器和“筛选”中的日期条件；本地 API 同步支持 `date=YYYY-MM-DD`。
- 等价 API 价格仍是按 Standard API 文本 Token 价格计算的估算值，不代表 ChatGPT 订阅额度或真实账单。

本版本已通过完整 Go 测试、`go vet`、16 项 Playwright Dashboard/demo 测试、四平台构建，并使用隔离数据库全量重扫 621 个本机 rollout。
