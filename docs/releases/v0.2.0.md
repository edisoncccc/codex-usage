# codex-usage v0.2.0

这是一次面向可读性、统计准确性与查询性能的功能级升级。Dashboard 继续只统计当前电脑，不代表 OpenAI 账号总用量或真实账单。

## 主要更新

- 全新“概览 / 每日 / 明细”Dashboard：默认聚焦重要信息，支持每日脉冲带、月历选日下钻、筛选 Chip、明暗主题、键盘操作和移动端布局。
- 新增每日统计：按规范 Token 事件的本地日期分桶，同一 Session 跨日产生的增量会分别计入对应日期，且补齐零用量日。
- 新增 Standard API 等价成本估算：内置截至 2026-07-31 核对的公开价格，展示已定价 Token 覆盖率，并支持模型别名和本机自定义单价。
- 新增 `/api/v1/cost-estimate`、`/api/v1/pricing` 与定价覆写接口；现有统计、导出和 CLI 接口保持兼容。
- 大幅缩短范围与视图切换时间：费用查询改为单次流式读取，前端按数据版本缓存并复用已加载结果。
- 修复 Microsoft Edge 可能复用旧 CSS/JS 导致页面近似“无样式”的问题；静态资源现在使用内容指纹和不可变缓存。
- 异常提示按类型和来源聚合；与 OTel 覆盖重叠、因而被安全抑制的状态库回退不再刷屏或计入可操作异常。
- 项目和本机存储命名从 `meter` 统一迁移为 `usage`。升级安装会保留历史数据，并迁移到 `usage.sqlite`。

## 准确性说明

- JSONL 规范事件按事件发生时间统计，不会把整个 Session 的 Token 都归到最后活跃日。
- OTel、JSONL 与状态库回退继续遵循覆盖期和去重规则；未知模型、累计总量回退或字段矛盾不会被当成零成本，而会进入未定价覆盖提示。
- API 等价成本按当前内置/本机价格重算本地 Token，只是估算，不读取 OpenAI 真实账单。

## 升级

下载对应平台文件后再次运行 `install`。安装器会停止旧用户级服务，迁移旧配置、SQLite/WAL 数据和 Codex OTel 管理标记，再启动 `codex-usage`。历史用量会继续保留。
